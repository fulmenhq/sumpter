# ClinVar Parallel Extraction Runbook (Alpha)

This runbook documents a safe, repeatable workflow for staging the ClinVar VCV Release XML for parallel extraction. It assumes the data is public and that we do **not** check large artifacts into git.

## Overview
- **Why**: Parallel extraction requires a seekable, uncompressed XML per ADR-0005.
- **Where**: Stage into a temporary workdir under `$SUMPTER_WORKDIR` or `${TMPDIR:-/tmp}`.
- **Safety**: Hash the uncompressed file, build the record index against the exact path, and clean up stale temp dirs with the provided helper.

## Staging Workflow
1) Pick a workdir (created per run):
   ```bash
   workdir=$(mktemp -d "${SUMPTER_WORKDIR:-${TMPDIR:-/tmp}}/sumpter-clinvar.XXXXXX")
   echo "Staging in $workdir"
   ```

2) Decompress once (uncompressed file will be ~60GB):
   ```bash
   gunzip -c /path/to/ClinVarVCVRelease.xml.gz > "$workdir/ClinVarVCVRelease.xml"
   ```

3) Record metadata for reuse and validation:
   ```bash
   size=$(stat -f %z "$workdir/ClinVarVCVRelease.xml")
   sha=$(shasum -a 256 "$workdir/ClinVarVCVRelease.xml" | awk '{print $1}')
   cat > "$workdir/.meta.json" <<EOF
   {"path":"$workdir/ClinVarVCVRelease.xml","size":$size,"sha256":"$sha"}
   EOF
   touch "$workdir/.ready"
   ```

4) Build the record index **against the uncompressed path**:
   ```bash
   sumpter index build "$workdir/ClinVarVCVRelease.xml" --selector //VariationArchive
   ```
   This produces a record index that parallel extraction can consume.

5) Run parallel extraction using the staged file and index:
   ```bash
   sumpter extract files \
     --record-index /path/to/ClinVarVCVRelease.recordindex.json \
     --source "$workdir/ClinVarVCVRelease.xml" \
     --workers 16
   ```
   The parallel extractor opens the same uncompressed file path per worker; no copies are made.

## Cleanup
- On success, remove the workdir:
  ```bash
  rm -rf "$workdir"
  ```
- To prune abandoned dirs (crashes, interrupts), use the helper:
  ```bash
  scripts/cleanup-workdirs.sh \
    --root "${SUMPTER_WORKDIR:-${TMPDIR:-/tmp}}" \
    --pattern "sumpter-clinvar.*" \
    --max-age-hours 24
  ```

## Notes
- Ensure disk space for the uncompressed file plus outputs and index.
- Keep `.meta.json` and `.ready` present until extraction finishes; they help the cleaner distinguish complete vs. in-progress staging.
- For repeat runs, reuse an existing staged file only if size and SHA256 match what the index expects.
