# Agentic Attribution Standard

**Project**: sumpter
**Governance**: Fulmen Ecosystem Standards
**Last Updated**: September 3, 2025

## Overview

The Agentic Attribution Standard defines the requirements and procedures for properly attributing AI agent contributions in the Sumpter project. This standard ensures transparency, accountability, and proper credit attribution for all AI-generated contributions.

## Purpose

### Why Attribution Matters

1. **Transparency**: Clear identification of AI-generated content
2. **Accountability**: Proper credit and responsibility assignment
3. **Quality Assurance**: Ability to review and validate AI contributions
4. **Legal Compliance**: Meeting intellectual property and licensing requirements
5. **Professional Standards**: Maintaining enterprise-grade development practices

### Scope

This standard applies to:

- All AI agent contributions to the codebase
- Documentation and technical specifications
- Design decisions and architectural choices
- Code reviews and quality assessments
- Process improvements and workflow optimizations

## Implementation Guidelines

### Commit Message Structure

#### Required Components

1. **Type and Description** (Conventional Commits format):

   ```
   type(scope): description
   ```

2. **Blank Line** (required separator)

3. **Attribution Block**:

   ```
   Generated by [Agent Name] ([Claude Code](https://claude.ai/code)) under supervision of [@3leapsdave](https://github.com/3leapsdave)

   Co-Authored-By: [Agent Name] <noreply@sumpterhq.dev>
   Authored-By: Dave Thompson <dave.thompson@3leaps.net> [@3leapsdave](https://github.com/3leapsdave)
   ```

#### Optional Components

4. **Body** (for complex changes):

   ```
   Detailed explanation of the change and its impact.
   ```

5. **Footer** (for breaking changes or issues):
   ```
   BREAKING CHANGE: [description]
   Closes #[issue-number]
   ```

### File-Level Attribution

For new files or significant file modifications:

```go
// Package-level attribution
// Generated by Sumpter contributor under supervision of @3leapsdave
// Last updated: 2025-09-03
package commands
```

### Documentation Attribution

For documentation contributions:

```markdown
## Change Log

### v0.1.0 - 2025-09-03

- **Documentation**: Updated repository operations SOP
  - Generated by Sumpter contributor under supervision of @3leapsdave
  - Reviewed and approved by @3leapsdave
```

## Validation Procedures

### Automated Validation

#### Pre-commit Hook

```bash
#!/bin/bash
# .git/hooks/pre-commit

# Validate commit attribution
if ! git log --oneline -1 | grep -q "Generated by.*under supervision of @3leapsdave"; then
    echo "❌ ERROR: Missing required AI agent attribution"
    echo "Please include proper attribution in commit message:"
    echo ""
    echo "Generated by [Agent Name] (Claude Code) under supervision of @3leapsdave"
    echo "Co-Authored-By: [Agent Name] <noreply@sumpterhq.dev>"
    echo "Authored-By: Dave Thompson <dave.thompson@3leaps.net> @3leapsdave"
    exit 1
fi

echo "✅ Attribution validation passed"
```

#### CI/CD Validation

```yaml
# .github/workflows/attribution-validation.yml
name: Attribution Validation

on: [push, pull_request]

jobs:
  validate-attribution:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0

      - name: Validate Commit Attribution
        run: |
          # Check recent commits for proper attribution
          if ! git log --oneline -10 | grep -q "Generated by.*under supervision of @3leapsdave"; then
            echo "❌ Recent commits missing required attribution"
            exit 1
          fi
```

### Manual Validation

#### Code Review Checklist

- [ ] Commit message includes proper attribution format
- [ ] Agent name matches registered agents
- [ ] Supervisor reference is correct (@3leapsdave)
- [ ] Co-Authored-By format is correct
- [ ] Authored-By includes full supervisor information
- [ ] Attribution is appropriate for the scope of changes

#### Attribution Audit Script

```bash
#!/bin/bash
# scripts/audit-attribution.sh

echo "=== AI Agent Attribution Audit ==="

# Check recent commits
echo "Recent commits attribution status:"
git log --oneline -20 --grep="Generated by" | head -10

# Count commits by agent
echo -e "\nCommits by agent:"
git log --oneline --all --grep="Generated by" | grep -o "Generated by [^ ]*" | sort | uniq -c

# Check for missing attribution
echo -e "\nCommits missing attribution:"
git log --oneline -20 | grep -v "Generated by" | head -5

echo -e "\nAudit complete"
```

## Compliance Requirements

### Mandatory Requirements

#### For AI Agents

- [ ] All commits must include proper attribution
- [ ] Attribution must reference correct supervisor (@3leapsdave)
- [ ] Agent name must match registered agents
- [ ] Attribution format must follow standard pattern
- [ ] Changes must be approved by supervisor

#### For Human Contributors

- [ ] Must review and validate AI agent attribution
- [ ] Must ensure attribution accuracy before merging
- [ ] Must maintain attribution integrity in rebases/squashes
- [ ] Must document attribution requirements for new contributors

### Quality Assurance

#### Attribution Quality Metrics

- **Completeness**: 100% of AI commits properly attributed
- **Accuracy**: All attribution information correct and current
- **Consistency**: Uniform attribution format across all contributions
- **Timeliness**: Attribution included at commit time, not retroactively

#### Validation Frequency

- **Pre-commit**: Automatic validation on every commit
- **CI/CD**: Validation on every push and PR
- **Weekly**: Manual audit of recent commits
- **Monthly**: Comprehensive attribution quality review

### Non-Compliance Consequences

#### Minor Issues

- Missing or incorrect agent name
- Formatting inconsistencies
- Supervisor reference errors

**Resolution**: Fix in subsequent commit with corrected attribution

#### Major Issues

- Complete lack of attribution
- False or misleading attribution
- Attribution bypass attempts

**Resolution**:

1. Immediate correction required
2. Documentation of incident
3. Process improvement implementation
4. Supervisor review and approval

### Training and Awareness

#### New Agent Onboarding

1. Review attribution standard completely
2. Practice with example commit messages
3. Validate understanding with test commits
4. Receive supervisor approval for first contributions

#### Ongoing Training

- Monthly attribution standard reviews
- Updates for new agents or process changes
- Training on attribution validation tools
- Best practices sharing and documentation

## Implementation Tools

### Attribution Helper Script

```bash
#!/bin/bash
# scripts/create-attributed-commit.sh

AGENT_NAME=$1
COMMIT_MESSAGE=$2

if [ -z "$AGENT_NAME" ] || [ -z "$COMMIT_MESSAGE" ]; then
    echo "Usage: $0 <agent-name> <commit-message>"
    echo "Example: $0 'Sumpter contributor' 'feat: implement XML parser'"
    exit 1
fi

FULL_MESSAGE="$COMMIT_MESSAGE

Generated by $AGENT_NAME (Claude Code) under supervision of @3leapsdave

Co-Authored-By: $AGENT_NAME <noreply@sumpterhq.dev>
Authored-By: Dave Thompson <dave.thompson@3leaps.net> @3leapsdave"

echo "Creating attributed commit..."
git add .
git commit -m "$FULL_MESSAGE"

echo "✅ Attributed commit created successfully"
```

### Attribution Validation Script

```bash
#!/bin/bash
# scripts/validate-attribution.sh

COMMIT_HASH=${1:-HEAD}

echo "Validating attribution for commit: $COMMIT_HASH"

# Check for required components
if ! git show --format=fuller --no-patch $COMMIT_HASH | grep -q "Generated by.*under supervision of @3leapsdave"; then
    echo "❌ Missing 'Generated by' with supervisor reference"
    exit 1
fi

if ! git show --format=fuller --no-patch $COMMIT_HASH | grep -q "Co-Authored-By:"; then
    echo "❌ Missing Co-Authored-By trailer"
    exit 1
fi

if ! git show --format=fuller --no-patch $COMMIT_HASH | grep -q "Authored-By: Dave Thompson"; then
    echo "❌ Missing Authored-By trailer for supervisor"
    exit 1
fi

echo "✅ Attribution validation passed"
```
