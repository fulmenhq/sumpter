# Sumpter v0.1.5 Release Notes

## Behavior changes

- **SUM-023 — multi-file extraction failure isolation.** `sumpter extract files` and `sumpter recipes run extract` now support `--continue-on-error` for multi-file cohorts. The flag is default-off and requires `--output-path`; recoverable per-file failures are written to `failures.json` while successful sibling files still emit outputs. Durable output and failure-manifest write failures remain terminal.
- **SUM-023 — signature mismatch routing.** Inputs that miss a recipe signature and then encounter declared `min_occurrences` floors now surface `signature mismatch` with confidence and threshold values instead of a misleading `min_occurrences violation`. Genuine post-signature `min_occurrences` shortfalls keep the existing error.
