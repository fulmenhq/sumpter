# v0.3.6 — Root-relative input provenance

**Release date:** 2026-09-23 · **Lifecycle:** alpha (interface-stability track; external contributions welcome)

Sumpter v0.3.6 adds an opt-in provenance root for local extraction inputs. When selected, inputs must be strictly contained by the root and their manifest paths are recorded relative to it. With the option unset, existing path sanitization behavior is unchanged.

**Start here:** [`docs/extract-workflow.md`](../extract-workflow.md#opt-in-root-relative-input-provenance) for the flag, containment rules, manifest marker, and input-ordinal table.

## Change set

- **Provenance-root input paths** — `--provenance-root` enables strict local-input containment and root-relative paths in provenance, identified by `input_path_form: "root_relative"`.

## Compatibility & dependencies

- Provenance-root behavior is opt-in; the default input-path behavior remains unchanged.
- No dependency updates are included in this release.
