# Sumpter v0.1.0 Release Notes

**Release Date:** 2025-09-18
**Theme:** Bootstrap — XML inspection foundations and quality gates

## Overview

Sumpter v0.1.0 is the initial bootstrap release. It establishes the project's
foundations: XML inspection with a dialect registry, a logging component with
console/JSON output and PII redaction, the Makefile quality gates and schema
validation tooling, and the first CLI command surface.

## Added

- Initial release: Sumpter v0.1.0 bootstrap
- XML inspection foundations with dialect registry and SEC EDGAR dialect
- Logging component with console/JSON output and PII redaction
- Makefile quality gates; schema validation via goneat; coverage scripts
- Embedded docs and schemas; CLI commands: version, envinfo, inspect, docs

## Fixed

- Errcheck issues in envinfo

## Docs
