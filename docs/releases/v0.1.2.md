# Sumpter v0.1.2 Release Notes

**Release Date:** TBD (In Progress)
**Theme:** Seekable-Zstd Compressed Index Store

## Overview

Sumpter v0.1.2 introduces a high-performance seekable-zstd compressed index store that dramatically reduces disk usage and memory requirements for large-scale XML indexing. This release enables parallel random access to compressed record indexes without loading multi-GB files into memory.

## Hero Feature: Seekable-Zstd Record Index Store

### The Problem

ClinVar-scale XML files (~3.7M records) generate record indexes exceeding 1GB in JSON format. Loading these indexes into memory for parallel extraction is wasteful and can cause OOM on constrained systems.

### The Solution

A two-file compressed index format using seekable-zstd:
- **Header file** (`*.recordindex.header.json`): Metadata, source info, and summary statistics
- **Records file** (`*.recordindex.records.szst`): Fixed-width binary records with parallel random access

### Key Benefits

| Metric | JSON Format | Seekable-Zstd | Improvement |
|--------|-------------|---------------|-------------|
| Disk Size | ~1 GB | ~50-100 MB | 10-20x smaller |
| Memory (streaming) | Constant | Constant | Same |
| Random Access | Sequential scan | O(1) seek | Parallel-ready |
| Compression | None | zstd (ratio ~10:1) | Transparent |

### Usage

```bash
# Build index with seekable-zstd output
sumpter index build clinvar.xml \
  --selector "//VariationArchive" \
  --emit-szst

# Outputs:
#   clinvar.recordindex.header.json
#   clinvar.recordindex.records.szst

# Stream-walk the compressed index (format auto-detected)
sumpter index stream clinvar.recordindex.header.json

# Verify index integrity
sumpter index verify clinvar.xml --index clinvar.recordindex.header.json

# Extract with compressed index (parallel workers)
sumpter extract files \
  --record-index clinvar.recordindex.header.json \
  --workers 8
```

## Technical Architecture

### Binary Record Format

Each record is encoded as a fixed-width 64-byte structure:

```
Offset  Size  Field
------  ----  -----
0       8     start_offset (int64, little-endian)
8       8     end_offset (int64, little-endian)
16      8     size_bytes (int64, little-endian)
24      4     depth (int32, little-endian)
28      4     record_num (int32, little-endian)
32      32    sha256 (raw bytes)
```

### Store Interface

```go
// IndexStore provides format-agnostic access to record indexes
type IndexStore interface {
    Header() (*index.RecordIndex, error)
    Records(ctx context.Context) (RecordIterator, error)
    Close() error
}

// Open auto-detects format by extension
store, err := store.Open(path)
// *.recordindex.json       → JSON store
// *.recordindex.header.json → Seekable-zstd store
```

### Build Requirements

Seekable-zstd support requires CGO:

```bash
# Build with seekable-zstd support
CGO_ENABLED=1 go build -tags seekablezstd ./cmd/sumpter

# Test seekable-zstd integration
CGO_ENABLED=1 go test -tags seekablezstd ./internal/index/store/...
```

## Compatibility

### Backward Compatibility
- JSON format (`*.recordindex.json`) remains fully supported
- Default output format is still JSON
- Existing indexes work without modification

### Forward Compatibility
- New `--emit-szst` flag is opt-in
- Both formats can coexist
- Format auto-detection makes switching transparent

## Dependencies

### New Dependencies
- `github.com/3leaps/seekable-zstd/bindings/go` - Seekable-zstd CGO bindings

### Platform Support
- Linux glibc (amd64) - Pre-built static library
- Linux musl (amd64) - Pre-built static library  
- macOS (arm64/amd64) - Build from source required
- Windows - Not yet supported

## Migration Guide

### Enabling Seekable-Zstd Output

```bash
# Generate both formats for transition period
sumpter index build input.xml \
  --selector "//Record" \
  --emit-json \
  --emit-szst

# Once validated, disable JSON output
sumpter index build input.xml \
  --selector "//Record" \
  --emit-json=false \
  --emit-szst
```

### Container Deployment

```dockerfile
# Use glibc-based image for seekable-zstd support
FROM golang:1.25-bookworm AS builder
RUN CGO_ENABLED=1 go build -tags seekablezstd -o /sumpter ./cmd/sumpter

FROM debian:bookworm-slim
COPY --from=builder /sumpter /usr/local/bin/
```
