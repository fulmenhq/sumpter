# Sumpter v0.1.10 Release Notes

**Release Date:** 2026-06-09
**Theme:** Homebrew + Scoop distribution; Intel-Mac prebuilt retired
**Status:** Prepared for release

## Overview

v0.1.10 makes Sumpter installable through the two package managers its users
already reach for, and trims the release matrix to the platforms worth shipping
prebuilt. It is a distribution-ergonomics release — there are no product-code
changes.

Two threads:

1. **Homebrew + Scoop distribution.** `brew install fulmenhq/tap/sumpter` and
   `scoop install fulmenhq/sumpter` now install Sumpter from the FulmenHQ tap and
   bucket, using the same raw-binary convention the v0.1.9 release already ships
   (no archives). This builds directly on v0.1.9's arch-complete matrix — the
   formula and manifest pin the published per-binary checksums.
2. **Supported-platform matrix change.** The Intel-Mac (`darwin-amd64`) prebuilt
   binary is retired. The release matrix is now five raw binaries.

## What's new

### Homebrew + Scoop install paths

Sumpter joins goneat, dimlox, and refbolt in the FulmenHQ tap and bucket:

```bash
# macOS (arm64) + Linux
brew install fulmenhq/tap/sumpter

# Windows (amd64 + arm64)
scoop bucket add fulmenhq https://github.com/fulmenhq/scoop-bucket
scoop install fulmenhq/sumpter
```

Both install from the raw release binaries — no archive/repackaging step. The
sumpter repo gains two thin delegation targets, `make update-homebrew-formula`
and `make update-scoop-manifest`, that refresh the sibling
`homebrew-tap`/`scoop-bucket` repos from a published tag. `RELEASE_CHECKLIST.md`
§ Distribution documents the post-release housekeeping end-to-end.

### Supported-platform matrix: `darwin-amd64` retired

The native Intel-Mac prebuilt is dropped. The release matrix is now **five** raw
binaries:

| OS      | amd64                       | arm64                       |
| ------- | --------------------------- | --------------------------- |
| linux   | `sumpter-linux-amd64`       | `sumpter-linux-arm64`       |
| darwin  | — (retired)                 | `sumpter-darwin-arm64`      |
| windows | `sumpter-windows-amd64.exe` | `sumpter-windows-arm64.exe` |

Rationale: prebuilt Intel-Mac support is being retired across the ecosystem (most
acute for CGO=1 projects, where macOS-amd64 build/runner support is aging out).
Sumpter's release build is a single-runner pure-Go cross-compile, so this is not
a CI-cost change today — it is a deliberate supported-platform decision that keeps
the published set aligned with where the ecosystem is heading.

## Behavior changes

- **`brew` / `scoop` are now first-class install paths** alongside direct
  download and `go install`.
- **No `darwin-amd64` prebuilt binary.** Intel-Mac users build from source — a
  source build on an Intel Mac produces a native `darwin-amd64`. The source
  build path is unchanged and supports all Go-supported platforms.
- **No product-code, output-format, or CLI changes.** Extraction, indexing, and
  the CLI surface are identical to v0.1.9.

## Deferred

- **Cloud URI read/write (S3 and S3-compatible) I/O** remains the next major
  capability thread and is tracked separately.
- **DuckDB, Arrow, service health endpoints, Prometheus metrics, adaptive
  backpressure, and repair modes** remain roadmap items.

## Upgrade notes

- **Version bump.** `VERSION` is `0.1.10`. Binaries from this tag emit `v0.1.10`
  via `sumpter version`.
- **Homebrew/Scoop.** After this tag is published and the tap/bucket PRs merge,
  `brew install fulmenhq/tap/sumpter` and `scoop install fulmenhq/sumpter`
  resolve `v0.1.10`.
- **Intel Mac.** If you previously pulled `sumpter-darwin-amd64`, build from
  source — `go install github.com/fulmenhq/sumpter/cmd/sumpter@v0.1.10` (or
  `make build`) produces a native `darwin-amd64` on an Intel Mac. Homebrew and
  the prebuilt binaries cover Apple Silicon (`darwin-arm64`) and the other four
  targets, not Intel Mac.
- **Release ceremony.** Use `SUMPTER_RELEASE_TAG=v0.1.10` for release targets.
  Tagging and pushing should happen only after CI, review, and the out-of-band
  public-surface/confidentiality checks are complete. Run the package-manager
  housekeeping (`make update-homebrew-formula` / `make update-scoop-manifest`)
  after the release is published.

## Validation summary

- `make release-build` produces the five raw binaries (no `darwin-amd64`), with
  `SHA256SUMS`/`SHA512SUMS` covering all five and `make release-verify-checksums`
  passing.
- `make update-homebrew-formula` / `make update-scoop-manifest` delegate cleanly
  to the sibling tap/bucket update targets (guarded when the siblings are absent).
- `make check-all`, `make verify-embeds`, and the confidentiality tree check
  green. No product-code changes.

Before tagging, CI must be green on the release-prep PR and the required
out-of-band security/confidentiality scans must be complete. The Homebrew and
Scoop PRs land as post-release housekeeping once the tag is published.
