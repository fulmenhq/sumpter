# Sumpter v0.1.1 Release Notes

## Overview

Sumpter v0.1.1 introduces significant enhancements to the XML processing engine, including new commands, improved security controls, and enhanced infrastructure tooling.

## New Features

### Commands
- **Extract Command**: New `sumpter extract` command with XPath-based XML processing capabilities
- **Retrieve Command**: New `sumpter retrieve` command with SEC EDGAR support for financial data acquisition
- **Enhanced Inspect**: Improved XML inspection with logging, deterministic ordering, and progress reporting

### Security & Infrastructure
- **Guardian Approval System**: Browser-based approval workflow for commits and pushes
- **License Compliance**: Automated license checking for dependencies
- **Enhanced Configuration**: Improved configuration system with better validation

### Processing
- **Dialect Support**: File signature-based dialect detection for XML processing
- **YAML Schema Registry**: Refactored dialect registry to YAML format with SEC EDGAR finance dialect

## Improvements

### Quality Assurance
- Updated golangci-lint configuration for better code quality
- Enhanced infrastructure tooling and quality gates
- Improved error handling and linting compliance

### Documentation
- Embedded architecture documentation (ADRs, SOPs)
- Schema-first and logging standard operating procedures
- Clarified repository operations and approval requirements

## Bug Fixes

- Resolved errcheck linting violations across test suites
- Fixed golangci-lint configuration issues
- Improved error handling in output functions

## Technical Details

### Dependencies
- Enhanced goneat integration for cross-platform asset embedding
- Updated tooling configurations for enterprise compliance

### Compatibility
- Maintains backward compatibility with v0.1.0
- All existing CLI commands and APIs preserved

## Migration Notes

No breaking changes from v0.1.0. All existing functionality remains intact.
