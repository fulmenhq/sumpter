# 18 Per-Record Verdict Matrix

Demonstrates derive-only `internal: true` staging helpers (XPath and Sumpter DSL
expressions), list-typed parameter prefix matching (`starts_with_any`),
multi-branch conditional (`? :`) per-record verdict classification
(`AUTO_APPROVE`, `MANUAL_REVIEW`, `REJECT_OUT_OF_BAND`), and opt-in
`value_profile` over the closed verdict domain.
